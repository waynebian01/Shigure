# Forever 地下城与团队副本列表

核对日期：2026-10-21。共 28 个地下城、9 个团队副本，两类各自从 1 开始编号；各类按推荐等级下限、上限、英文名称升序排列。

等级使用 Wowhead Forever 概览的推荐范围，不是最低入场等级。新地下城采用概览顶部经蓝帖更正的等级表；共享同一实例 ID 的血色修道院、玛拉顿、黑石塔分区合并为一项，等级取各分区的范围。列表包含经典副本及已宣布的 Forever 新副本，不代表目前均已开放；任务场景、测试地图、未宣布副本不列入。

游戏副本 ID 是 `GetInstanceInfo()` 的第八个返回值，与 Wowhead 地区 ID、C_Map 界面地图 ID 不同。34 项已有客户端记录并写入 Lua 的 `dungeonIndex` / `raidIndex`；3 项地下城仅预留编号，JSON 的 `sourceId: 0` 表示待核实，不写入 Lua 映射。进入地下城时“团队副本”为 0，进入团队副本时“地下城”为 0。后续补齐 ID 时保持编号不变。

尚未核对简体中文名称的新增副本保留英文名。
