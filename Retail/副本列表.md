# Retail 地下城与团队副本列表

核对日期：2026-10-21。按 Wowhead 正式服目录整理，共 150 个地下城、65 个团队副本，两类各自从 1 开始编号。

资料片按经典旧世 → 燃烧的远征 → 巫妖王之怒 → 大地的裂变 → 熊猫人之谜 → 德拉诺之王 → 军团再临 → 争霸艾泽拉斯 → 暗影国度 → 巨龙时代 → 地心之战 → 至暗之夜排列。同一资料片内按 Wowhead 地区 ID 升序，资料片归属沿用目录（例如重制副本归入目录标注的版本），不表示补丁开放顺序。

Wowhead 的地下城目录有 166 条地区记录，团队副本目录有 73 条。同一游戏实例 ID 的分区、别名、重复记录合并，采用主要副本名并保留 `mergedZones` 来源；不同实例 ID 的同名副本分别保留。目录中的任务、节日、周年庆和特殊条目一并保留，能从客户端名称确定的用途显示在备注中；列入目录不代表目前已开放。

`sourceId` 是 `GetInstanceInfo()` 第八个返回值对应的游戏实例 ID，经客户端 `AreaTable.ContinentID → Map.ID` 核实，不是 Wowhead 地区 ID，也不是 `C_Map` 界面地图 ID。两类编号同步到 `Fuyutsui.dungeonIndex` / `Fuyutsui.raidIndex`，非对应类型或未配置时输出 0。潮缚石窟（2987）按目录和客户端类型归入团队副本。

**本次按版本重排会改变旧 Retail 编号。引用旧编号的模块条件和数字数组需要对照本表更新。** 副本技能参考页直接使用本目录；技能数据的 `instanceId` 保存游戏实例 ID，界面显示地下城／团队副本类型及对应的新编号。
